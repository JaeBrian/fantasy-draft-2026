# Weekly environment sources

Verified live September 7, 2026 Pacific (September 8 UTC). The collector uses the same bounded, cached source helper as weekly projections, with one-hour weather/report/scoreboard cache lifetimes and a 30-day coordinate cache. It makes no roster requests.

- [NFL official week 1 injury table](https://www.nfl.com/injuries/league/2026/reg1): 11 practice rows, all with blank injury details and game designations at collection. Empty values remain null. Collection time is distinct from report publication time, which this table omits. The parser requires the requested year and week in the page title. Missing rows never establish health. Final inactive lists remain a separate game-day source.
- [ESPN event scoreboard](https://site.api.espn.com/apis/site/v2/sports/football/nfl/scoreboard?dates=2026&seasontype=2&week=1&limit=1000): all 16 current-week games, kickoff, actual event venue/city, indoor flag and neutral-site flag. Season, week, event ID and both teams are checked. Venue assignment uses the event, including overseas games.
- [nflverse games](https://github.com/nflverse/nfldata/blob/master/data/games.csv): canonical game IDs, scheduled stadium IDs and earlier regular-season kickoff times. Rest is elapsed days from the prior kickoff. Week 1 remains null; the schedule's default seven-day rest value would imply an unsupported prior-game baseline.
- [Stadium coordinate registry](https://github.com/greerreNFL/stadiums): author-maintained stadium coordinates linked by scheduled stadium ID and cross-checked against the event city or exact stadium name. This is a community coordinate dataset, not official NFL venue metadata. Roof data is deliberately excluded: both this registry and nflverse incorrectly label Melbourne Cricket Ground a dome. ESPN identifies that event as outdoors.
- [MCG official game announcement](https://www.mcg.org.au/news/2026/march/nfl-confirms-date-for-2026-melbourne-game): confirms Rams–49ers at Melbourne Cricket Ground September 11, 10:35 a.m. AEST, matching ESPN's September 11 00:35 UTC. The Rams' home stadium is irrelevant to this game's weather.
- [Open-Meteo forecast documentation](https://open-meteo.com/en/docs): nearest kickoff hour in UTC, degrees Fahrenheit, wind/gust mph, precipitation inches and source precipitation probability. Rainfall describes the preceding hour. Only complete future hourly records within the forecast horizon are returned. No conversion into player performance or injury probabilities. Provider model issuance timestamps remain unknown.
- [Lucas Oil Stadium background](https://www.lucasoilstadium.com/tours-stadium-info/background-history/) and [State Farm Stadium](https://www.statefarmstadium.com/stadium-info-2/about-2): retractable roof construction does not establish game-day roof position. Houston, Indianapolis, Atlanta, Dallas and Arizona retain unknown retractable operation. SoFi uses covered/open-sided exposure, consistent with the [Chargers venue guide](https://static.clubs.nfl.com/image/upload/v1606870383/chargers/txw6assy6dudk8zvaw0a.pdf). Weather outside these structures remains context only.
- [NFL Melbourne arrival report](https://www.nfl.com/news/niners-arrive-melbourne-historic-nfl-game-rams): 49ers arrived September 4 after a 15-hour flight. Stored as sourced travel context with article publication time, without a numerical penalty.

Live collection returned 16 games with verified coordinates, 13 hourly weather records, 3 indoor exclusions, 11 official practice rows and no failed fetches. Seattle's nearest-hour forecast was 74.9°F, 6 mph wind; Melbourne's was 55.9°F, 0.5 mph wind. These are forecasts captured at approximately 2026-09-08 05:36 UTC, not game observations. Raw responses remain in the shared weekly cache.

`collectEnvironment({season,week,now})` returns sources, games, injuries and limitations. Games use canonical nflverse IDs (`2026_01_SF_LA`), canonical team aliases (`LAR`), numeric UTC kickoff milliseconds, a venue object, `roof`, nullable `weather`, `{home,away}` restDays, optional sourced travel entries and evidence strings. Official name matching requires a unique same-team, same-position normalized full name; suffixes remain significant. It returns null for ambiguous matches.

Verification: nine deterministic tests cover report season/week isolation, blank status preservation, team/position/name ambiguity, Melbourne roof conflict, retractable/covered handling, nearest-hour selection and missing/indoor weather. A real week-1 collection verifies external parser and feed compatibility. Future forecast accuracy and individual travel/weather effects remain unvalidated.

Cutoff handling: ordinary runs accept observations collected during the run and timestamp the completed artifact afterward. An explicit `now` is strict: observations after it are rejected. Historical cutoffs older than 60 seconds and future cutoffs require a separately archived environment snapshot and are rejected before network collection. Tests cover both strict cutoffs and normal in-flight collection.
